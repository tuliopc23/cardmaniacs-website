# Marketing surface components

Reader-first compositions for launch pages. Use with tokens in `global.css` (`--reader-*`, `.marketing-reader-prose`).

| Component                    | Use                                   |
| ---------------------------- | ------------------------------------- |
| `MarketingReaderSurface`     | Article/reader hero, blog shell       |
| `MarketingHighlightSurface`  | Highlights killer sections            |
| `MarketingTriageSurface`     | Feed/card triage                      |
| `MarketingCommandSurface`    | Palette / power-user                  |
| `MarketingMediaSurface`      | YouTube/podcast story                 |
| `MarketingDeviceComposition` | Screenshot framing via `ProductFrame` |

Props accept `class` for layout. Slot content goes inside `MarketingReaderSurface`.
