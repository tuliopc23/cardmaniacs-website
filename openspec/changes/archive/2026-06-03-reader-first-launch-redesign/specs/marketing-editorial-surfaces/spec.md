## ADDED Requirements

### Requirement: Blog uses Reader design language

The blog index SHALL feel like a reading library; blog detail SHALL use `MarketingReaderSurface` (or equivalent) with Markdoc element styling.

#### Scenario: Blog post reading

- **WHEN** a visitor reads a blog post
- **THEN** typography, spacing, and surface treatment align with Cardmaniacs Reader—not a generic article template

### Requirement: Changelog and releases use app-like release notes

Changelog index SHALL use version cards, platform pills, and type badges; detail pages SHALL use Reader layout. Release pages SHALL match changelog treatment.

#### Scenario: Changelog entry

- **WHEN** a visitor opens a changelog entry
- **THEN** release notes read inside a calm elevated surface consistent with the app

### Requirement: Pricing uses native surface language

The pricing page SHALL avoid generic SaaS pricing-card clichés and use calm plan surfaces aligned with the app.

#### Scenario: Pricing page

- **WHEN** a visitor reviews plans
- **THEN** layout and components match Cardmaniacs marketing surfaces
