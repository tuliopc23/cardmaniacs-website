Before launch, the site SHALL satisfy M8 criteria: no Coming soon on primary surfaces; no fake download CTAs; Reader visual parity; comprehensive Features page; editorial alignment; intentional themes; mobile polish; a11y; stable images; `vp check` and `vp test` pass.

#### Scenario: Ship gate

- **WHEN** M8.12 completes
- **THEN** validation commands pass and M8.13 ship report lists changed files, components, pages, asset gaps, and commands run

### Requirement: Ship report is delivered

A concise ship report SHALL document remaining content/assets needed after implementation.

#### Scenario: Handoff

- **WHEN** launch work is marked complete
- **THEN** stakeholders receive the ship report artifact
