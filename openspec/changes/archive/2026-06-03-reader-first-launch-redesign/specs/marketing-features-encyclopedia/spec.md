## ADDED Requirements

### Requirement: Features page covers the full product map

The Features page SHALL include eight major sections: Feeds & Syndication; Read Later & Parsing; Reader & Highlights; Read Aloud; Navigation & Power User; Organization; Native Extensions; Designed for Every Apple Device.

#### Scenario: Launch reference

- **WHEN** a stakeholder needs launch feature coverage
- **THEN** the Features page alone documents RSS/Atom/JSON, social sources (as supported/planned), media players, parsing types, highlights, Read Aloud, palette/Vim, organization, extensions, and per-device craft

### Requirement: Each Features section has a visual object

Each major section SHALL include a marketing surface or wired screenshot slot—not text-only cards.

#### Scenario: Section layout

- **WHEN** any Features section renders
- **THEN** a visual component or screenshot slot is present alongside copy
